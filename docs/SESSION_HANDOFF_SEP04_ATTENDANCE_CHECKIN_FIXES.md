## 2. ผลการวิเคราะห์หาสาเหตุเชิงลึก (Detailed Root Cause Analysis)

### กรณีที่ 1: ตี๋ (ชยุต กุลธนาวัฒน์ - 491-67) — *"ตี๋ เช็คเอ้าไม่ได้ 20:40"*
- **หน้าที่/สถานที่:** ขับรถประจำบ้านท่านประธาน
- **ลำดับเหตุการณ์จริง:**
  1. ตี๋เช็คอินเข้างานตอนเช้าเวลา **06:57 น.**
  2. กดเช็คเอาท์รอบแรกเวลา **18:09 น.**
  3. ได้รับมอบหมายให้อยู่ปฏิบัติหน้าที่ต่อ / ทำโอที จนถึงเวลา **20:40 น.**
  4. เมื่อเปิดแอปเวลา 20:40 น. เพื่อจะเช็คเอาท์ หน้าจอขึ้นสถานะ `isFullyCheckedOut` ("เสร็จสิ้นการทำงานวันนี้แล้ว: เช็คอิน 06:57, เช็คเอาท์ 18:09") โดย **ไม่มีปุ่มให้เช็คเอาท์ซ้ำ หรืออัปเดตเวลาออกงาน**
  5. ฝั่ง Backend เดิม ฟังก์ชัน `checkOut()` ตรวจหาเฉพาะแถวที่ `checked_out_at IS NULL` เมื่อไม่พบจะคืนค่า error ทันทีว่า *"ยังไม่ได้เช็คอินวันนี้"* ตี๋จึงไม่สามารถเช็คเอาท์รอบ 20:40 น. ได้

### กรณีที่ 2: ณัฐฐา ปูน (ณัฐฐา ปักคำมา - 492-67) — *"ไซต์งานเช็คเอ้าไม่ได้"*
- **หน้าที่/สถานที่:** ประจำไซต์ SCG ปูนซิเมนต์ไทย แก่งคอย สระบุรี (มีสิทธิ์ `outsideHeadOfficeEligible`)
- **ลำดับเหตุการณ์จริง:**
  1. ณัฐฐาเดินทางไปถึงไซต์งานและเริ่มงานตามปกติ แต่ **ไม่ได้เปิดแอปเพื่อกดเช็คอินตอนเช้า** (เน็ตหน้างานขัดข้อง หรือลืม)
  2. เมื่อถึงเวลาเลิกงานตอนเย็น (**17:05 น.**) ณัฐฐาเปิดแอปขึ้นมาเพื่อจะกด **"เช็คเอาท์"**
  3. เนื่องจากในระบบยังไม่มีแถวข้อมูลเช็คอินของวันนั้น หน้าจอจึงแสดงเฉพาะปุ่ม **"เช็คอินนอก Head Office"** พร้อมแถบสีแดงแจ้งเตือนว่า **"มาสาย 545 นาที — หัวหน้าจะได้รับแจ้งเตือน"** โดย **ไม่มีปุ่มเช็คเอาท์แสดงอยู่เลย**
  4. พนักงานจึงตกใจและสับสน ไม่กล้ากดเช็คอินเพราะกลัวระบบตัดว่ามาสาย 9 ชั่วโมง และคิดว่าระบบไซต์งานเกิดข้อผิดพลาดจนกดเช็คเอาท์ไม่ได้

### กรณีที่ 3: Android WebView Error — *"This page couldn't load..."*
- **สาเหตุ:** สัญญาณอินเทอร์เน็ตมือถือบริเวณไซต์งานสระบุรีเกิดอาการขาดหาย/สลับเสาสัญญาณชั่วคราวขณะโหลดหน้าเว็บตอน 17:05 น. และตัวระบบเดิมของ `/portal` ยังไม่มี **Error Boundary (`error.tsx`)** คอยดักจับฝั่ง Client ทำให้ Android WebView หลุดจากการ render ของ React ไปยังหน้า Error เริ่มต้นของระบบปฏิบัติการ Android

## 4. รายละเอียดการปรับปรุงโค้ดระบบ (Code Changes)

### 1. `src/app/portal/checkin/actions.ts`
- **ปรับปรุง `checkOut()`**:
  - หากไม่พบเช็คอินที่ยังเปิดอยู่ (`checked_out_at IS NULL`) ระบบจะค้นหาประวัติการเช็คอินที่เคยเช็คเอาท์ไปแล้วของวันนี้ (`alreadyCheckedOut`)
  - หากพบ จะทำการอัปเดต `checked_out_at = new Date().toISOString()` ให้ทันที เพื่อรองรับกรณีทำโอทีหรืออยู่ปฏิบัติหน้าที่ต่อ
- **เพิ่มฟังก์ชัน `checkOutWithMissedCheckin(payload)`**:
  - รับค่า `approximateStartTime` (ค่าเริ่มต้น 08:00 น.), `reason`, `latitude`, `longitude`
  - ทำการสร้างแถวบันทึกเวลาเข้างานตามเวลาย้อนหลังที่ระบุ และลงเวลาออกงานเป็นเวลาปัจจุบันทันทีในคำสั่งเดียว พร้อมแนบหมายเหตุให้ HR ตรวจสอบได้

### 2. `src/app/portal/checkin/checkin-view.tsx`
- **กรณีเช็คเอาท์ไปแล้ว (`isFullyCheckedOut` และ `isCardCheckedOut`):**
  - เพิ่มปุ่ม **"อัปเดตเวลาเช็คเอาท์ (ทำงานต่อ / OT ถึงปัจจุบัน)"** พร้อมกล่องยืนยันที่แสดงเวลาเช็คเอาท์เดิมและเวลาเช็คเอาท์ใหม่
- **กรณีช่วงเย็นและยังไม่ได้เช็คอิน (ตั้งแต่ 15:00 น. เป็นต้นไป):**
  - แสดงการ์ดแนะนำ: *"เลิกงานแล้ว แต่ลืมเช็คอินตอนเช้า? สามารถบันทึกเวลาออกงานพร้อมระบุเวลาเข้างานย้อนหลังได้ทันที"*
  - มีปุ่ม **"บันทึกเวลาออกงาน (ลืมเช็คอินตอนเช้า)"** ซึ่งจะเปิด Modal ให้ระบุเวลาเข้างานเช้าและเหตุผล โดยดึงพิกัด GPS อัตโนมัติ
  - ปรับข้อความแจ้งเตือนมาสายช่วงเย็น ให้แนะนำพนักงานกดปุ่มบันทึกเวลาออกงานแทนการตกใจกับตัวเลขมาสาย

### 3. `src/app/portal/error.tsx` และ `src/app/error.tsx`
- ติดตั้ง Client-side Error Boundary พร้อมข้อความภาษาไทย
- มีปุ่ม "โหลดใหม่อีกครั้ง" และปุ่ม "กลับหน้าหลัก" เพื่อป้องกันไม่ให้ Android WebView ตัดไปแสดงหน้าจอดำ/จอค้างเวลาระบบเครือข่ายมีปัญหา
